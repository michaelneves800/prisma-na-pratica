Seu projeto de revisão

Defina a pergunta e documente as escolhas desde a primeira busca. Esta ferramenta acompanha novas revisões e gera um fluxograma didático com duas rotas de identificação.

Funciona offline após o download. Salvar cópia HTML gera outro arquivo com o projeto preenchido. O backup JSON permite restaurar os dados nesta ferramenta.

Identificação da pesquisa

Um percurso para trabalhar

1. Cadastre as buscas

Registre fonte, expressão, data, filtros e quantidade antes da remoção de duplicatas.

2. Acompanhe as decisões

Use o diário de registros ou importe uma tabela CSV. Título e resumo, recuperação e leitura integral são etapas diferentes.

3. Confira as contagens

Informe os totais por etapa ou atualize-os a partir de um diário completo de registros.

4. Relate e preserve

Exporte o fluxograma, confira o checklist 2020 e guarde uma cópia do projeto.
